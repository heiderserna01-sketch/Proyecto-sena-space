VERIFICACIÓN DE MÓDULOS HTML

Módulos principales:
- usuario.html
- recursos.html
- prestamos.html
- administrador.html

Navegación interna:
usuario.html -> recursos.html / prestamos.html / administrador.html / home.html
recursos.html -> prestamos.html / usuario.html / administrador.html / home.html
prestamos.html -> recursos.html / usuario.html / administrador.html / home.html
administrador.html -> usuario.html / recursos.html / prestamos.html / home.html
home.html -> usuario.html / recursos.html / prestamos.html / administrador.html

Se eliminaron las referencias de navegación de estos módulos a usuario.php y administrador.php.
Los PHP quedan como backend/API/autenticación; las pantallas de los módulos principales se abren como HTML.

Cada módulo mantiene SB Admin 2 + custom.css + modulo_recursos.css.
Las páginas Recursos y Préstamos siguen consumiendo recursos_api.php mediante fetch, por lo que requieren Apache/PHP/MySQL para las operaciones dinámicas.
