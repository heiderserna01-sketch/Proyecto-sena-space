VERIFICACIÓN COMPLETA DEL PROYECTO
==================================

Se revisó la versión integrada para evitar que falten archivos o piezas del flujo.

MÓDULOS HTML
------------
1. usuario.html       -> entrada HTML del módulo usuario.
2. recursos.html      -> catálogo/inventario de recursos y acceso a solicitud.
3. prestamos.html     -> solicitud, fechas, cantidad, motivo y verificación de disponibilidad.
4. administrador.html -> panel administrativo HTML: aprobaciones, prestados, devoluciones, inventario, roles e historial.

MÓDULOS PHP
-----------
1. login.php           -> autentica y determina rol.
2. usuario.php         -> panel usuario con sesión.
3. administrador.php   -> panel administrador con protección de rol.
4. recursos_api.php    -> API única para recursos, disponibilidad, solicitudes, aprobaciones, devoluciones, reposiciones, inventario, roles e historial.
5. conexion.php        -> conexión MySQL/MariaDB.
6. logout.php          -> cierre de sesión.
7. register.php        -> registro existente del proyecto.
8. acceso.php          -> módulo existente del proyecto.

BASE DE DATOS
-------------
sena_space.sql y recursos_schema.sql incluyen la ampliación del sistema.

Tablas del módulo:
- recursos
- solicitudes
- reposiciones
- historial_recursos
- admin.rol_sistema

VERIFICACIONES IMPLEMENTADAS
----------------------------
- Sesión requerida para consultar/crear solicitudes.
- Rol Administrador requerido para acciones administrativas.
- Disponibilidad por rango de fechas.
- Se descuentan solicitudes Pendientes y Aprobadas que se solapan.
- Revalidación de disponibilidad al aprobar, para evitar sobreasignación.
- Cantidad mínima >= 1.
- Fecha inicio <= fecha devolución.
- Estado del recurso Disponible/Mantenimiento/Baja.
- Registro de acciones administrativas en historial.
- Solicitud y confirmación de devolución.
- Control de stock mínimo y reposición.
- Cambio de rol protegido para administrador.

COMUNICACIÓN
------------
HTML -> recursos_api.php -> MySQL -> mismo dato para usuario y administrador.

No se necesita otro archivo adicional para el flujo Recursos/Préstamos/Administrador.
Los archivos demo de SB Admin 2 que ya pertenecían al proyecto se conservaron.
